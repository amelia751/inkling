# Marketing site style

Read and follow `apps/site/AGENTS.md` (the site's style guide) before changing anything in
`apps/site`.

- Use only the tokens in `apps/site/src/site.css`.
- Keep copy in `apps/site/src/content.ts`.
- Give every new animation a reduced-motion still state.
